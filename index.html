I'm a Computer Science Honours graduate from the University of Manitoba with a passion for building software that's clean, reliable, and production-ready. I've spent the last three years shipping real code across consulting, fintech, travel, and education.

My sweet spot is full-stack development and backend APIs — whether that's building React and Next.js interfaces, wiring up GraphQL mutations in Rails, or writing services in Go. I care deeply about correctness, thoughtful architecture, and systems that hold up under load.

Beyond the terminal, I'm passionate about AI-assisted learning tools, having built features for Qstudy — an app that transforms studying with short-form videos, flashcards, and AI-generated content. I'm always curious about the intersection of software and education.

Currently an Associate Software Engineer at Norima Consulting, building modern web applications with Next.js and TypeScript.
