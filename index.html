03 · Probabilistic AI

GibbsNet

Image denoising with Gibbs sampling. Each pixel is treated as a random variable whose posterior combines a Gaussian prior from its four neighbours with the observed noisy value through Bayes' rule. Over 50,000 sampling iterations it restores a noisy greyscale image, with the original, noisy and denoised results plotted side by side.

PythonNumPyMatplotlibBayesian inference

04 · Computer vision

DigitVision

A convolutional neural network trained on MNIST's 60,000 handwritten digits to measure how much feature extraction matters. The network stays fixed while the input changes: a bad extractor adds Gaussian noise, a good one applies an OpenCV sharpening filter. It plots validation loss per epoch and reports test accuracy for each.
